# Лабораторная работа 1

## Задание 1. Множество Мандельброта

Программа получает из командной строки количество потоков и количество точек:

```bash
./task1_mandelbrot nthreads npoints
```

Например:

```bash
./task1_mandelbrot 4 500000
```

## Как работает программа

Для случайной точки `(x, y)` создаётся комплексное число `c = x + yi`.
Затем 1000 раз вычисляется:

```text
z = z * z + c
```

Начальное значение `z` равно нулю. Если квадрат модуля `z` становится не
меньше 4, точка не входит в множество. Если этого не произошло за 1000
итераций, программа сохраняет точку.

Координаты генерируются в диапазонах:

```text
-2.0 <= x <= 1.0
-1.5 <= y <= 1.5
```

Результат записывается в `mandelbrot.csv`. Каждая строка содержит `x,y`.

## Потоки

Точки делятся между потоками примерно поровну. Потоки создаются через
`pthread_create`, а главный поток ждёт их завершения через `pthread_join`.

У каждого потока свой генератор случайных чисел и свой участок итогового
массива. Два потока не записывают данные в один элемент, поэтому мьютекс здесь
не нужен.

## Сборка

```bash
make task1_mandelbrot
```

## Замеры

Замеры сделаны на macbook air M5 (10 cpu, arm65) и 24 ГБ озу.
Программа  собрана с флагами `-O2` и `-pthread`.

Для каждого количества потоков программа находила 500 000 точек. Каждый
вариант запускался 5 раз. В таблице указано среднее время. Запись CSV в замер
не входила.

| Потоки | Среднее время, с | Ускорение | Эффективность |
|------:|------------------:|----------:|--------------:|
| 1     | 1,095             | 1,00      | 1,00          |
| 2     | 0,558             | 1,96      | 0,98          |
| 4     | 0,286             | 3,82      | 0,96          |
| 8     | 0,190             | 5,75      | 0,72          |
| 10    | 0,162             | 6,76      | 0,68          |

Ускорение считалось по формуле:


## Задание 2. Задача N тел

Программа получает количество потоков, конечное время расчёта и файл с
начальными данными:

```bash
./task2_nbody nthreads tend input_file
```

В первой строке входного файла записано количество тел. Дальше для каждого
тела указываются масса, три координаты и три компоненты скорости:

```text
mass x y z vx vy vz
```

## Как работает программа

На каждом шаге программа рассчитывает силу притяжения между всеми парами тел.
Одна пара считается только один раз. Сила для второго тела равна силе для
первого тела с противоположным знаком, как следует из третьего закона Ньютона.

После расчёта сил координаты и скорости меняются методом Эйлера с шагом
`dt = 0.01`:

```text
new_position = old_position + old_velocity * dt
new_velocity = old_velocity + force / mass * dt
```

Расчёт выполняется в трёх измерениях. В `nbody.csv` записываются время и
координаты `x`, `y` всех тел:

```text
t,x1,y1,x2,y2,...,xN,yN
```

## Потоки

Пары тел распределяются между потоками. У каждого потока есть свой массив
сил, поэтому несколько потоков не изменяют одну переменную одновременно и
мьютекс не нужен. После `pthread_join` главный поток складывает частичные силы,
а затем обновляет координаты и скорости тел.

## Сборка

```bash
make task2_nbody
```

## Замеры

Для замеров использовались 800 искусственных тел массой 100 000, расставленных
по сетке с нулевыми начальными скоростями. Конечное время `tend = 10`, шаг
`dt = 0.01`, поэтому выполнялось 1000 шагов расчёта. Каждый вариант запускался
5 раз, в таблице указано среднее время.

| Потоки | Среднее время, с | Ускорение | Эффективность |
|------:|------------------:|----------:|--------------:|
| 1     | 0,608             | 1,00      | 1,00          |
| 2     | 0,408             | 1,49      | 0,75          |
| 4     | 0,267             | 2,28      | 0,57          |
| 8     | 0,252             | 2,41      | 0,30          |
| 10    | 0,260             | 2,34      | 0,23          |

Лучшее среднее время получилось на 8 потоках - 0,252 секунды. На 10 потоках
программа стала немного медленнее. Это связано с расходами на создание
потоков, ожидание через `pthread_join` и сложение отдельных массивов сил.
